# 바둑알 십자 뒤집기

* 문제 번호: 1097
* 출처: CodeUp
* 난이도: 기초
* 사용 언어: C++
* 문제 링크: https://codeup.kr/problem.php?id=1097

## 문제 요약

19×19 크기의 바둑판에서 지정된 좌표를 중심으로 가로줄과 세로줄의 바둑돌 상태를 뒤집는 문제입니다.

바둑돌이 없는 위치는 `0`, 바둑돌이 있는 위치는 `1`로 표현하며, 선택된 줄의 모든 값은 `0 → 1`, `1 → 0`으로 변경합니다.

## 입력

* 19×19 크기의 바둑판 상태가 입력됩니다.
* 십자 뒤집기를 수행할 횟수가 입력됩니다.
* 각 뒤집기의 중심 좌표인 행과 열이 입력됩니다.

## 출력

모든 십자 뒤집기를 수행한 후의 19×19 바둑판 상태를 출력합니다.

## 풀이 아이디어

1. 19×19 크기의 2차원 배열에 바둑판 상태를 저장합니다.
2. 입력받은 좌표를 기준으로 해당 열의 모든 값을 뒤집습니다.
3. 같은 좌표를 기준으로 해당 행의 모든 값을 뒤집습니다.
4. 모든 뒤집기 작업이 끝난 바둑판을 출력합니다.

입력 좌표는 `1`부터 시작하지만 배열의 인덱스는 `0`부터 시작하므로, 좌표를 사용할 때 `1`을 빼야 합니다.

## 핵심 코드

```cpp
for (int i = 0; i < number; i++)
{
  cin >> row >> col;

  // 선택한 열 뒤집기
  for (int j = 0; j < 19; j++)
  {
    board[j][col - 1] = 1 - board[j][col - 1];
  }

  // 선택한 행 뒤집기
  for (int j = 0; j < 19; j++)
  {
    board[row - 1][j] = 1 - board[row - 1][j];
  }
}
```
