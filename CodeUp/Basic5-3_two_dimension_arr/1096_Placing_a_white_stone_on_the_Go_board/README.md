# 바둑판에 흰 돌 놓기

* 문제 번호: `1096`
* 출처: CodeUp
* 사용 언어: C++
* 분류: 2차원 배열
* 문제 링크: https://codeup.kr/problem.php?id=1096

## 문제 설명

19×19 크기의 바둑판에 흰 돌을 놓을 좌표가 주어집니다.

흰 돌이 놓인 위치는 `1`, 흰 돌이 없는 위치는 `0`으로 표시하여 전체 바둑판의 상태를 출력하는 문제입니다.

## 풀이 아이디어

1. 모든 값을 `0`으로 초기화한 19×19 크기의 2차원 배열을 선언합니다.
2. 흰 돌의 개수만큼 행과 열의 좌표를 입력받습니다.
3. 입력받은 좌표에 해당하는 배열의 값을 `1`로 변경합니다.
4. 이중 반복문을 사용하여 바둑판 전체를 출력합니다.

문제에서 주어지는 좌표는 `1`부터 시작하지만, C++ 배열의 인덱스는 `0`부터 시작합니다.

따라서 입력받은 행과 열에서 각각 `1`을 빼서 배열에 접근합니다.

## 핵심 코드

```cpp
int board[19][19] = {0, };

for (int i = 0; i < number; i++)
{
    cin >> row >> col;
    board[row - 1][col - 1] = 1;
}

for (int i = 0; i < 19; i++)
{
    for (int j = 0; j < 19; j++)
    {
        cout << board[i][j] << " ";
    }

    cout << '\n';
}
```

## 시간 복잡도

흰 돌의 개수를 `N`이라고 할 때, 좌표를 입력받아 배열에 표시하는 과정은 `O(N)`입니다.

바둑판 출력은 19×19번 반복하므로 전체 시간 복잡도는 다음과 같습니다.

```text
O(N + 19 × 19)
```

바둑판의 크기가 고정되어 있으므로 상수 시간으로 표현하면 `O(N)`으로 볼 수 있습니다.

## 공간 복잡도

19×19 크기의 고정 배열을 사용합니다.

```text
O(19 × 19) = O(1)
```

## 주의할 점

* 문제의 좌표는 `1`부터 시작합니다.
* C++ 배열의 인덱스는 `0`부터 시작합니다.
* 입력받은 좌표를 그대로 사용하지 않고 `row - 1`, `col - 1`로 변환해야 합니다.
* 행과 열의 순서를 바꾸지 않도록 주의해야 합니다.

## 배운 점

* 2차원 배열을 선언하고 초기화하는 방법
* 행과 열 좌표로 배열의 특정 위치에 접근하는 방법
* 문제의 좌표와 배열 인덱스가 다를 때 변환하는 방법
* 이중 반복문으로 2차원 배열 전체를 순회하는 방법
