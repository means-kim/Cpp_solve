# [기초-배열연습] 2차원 배열 순서대로 채우기 1-1

* 문제 번호: 1460
* 출처: CodeUp
* 난이도: 기초
* 사용 언어: C++
* 문제 링크: https://codeup.kr/problem.php?id=1460

## 문제 요약

정수 `n`을 입력받아 `n × n` 크기의 2차원 배열을 만들고, 왼쪽 위부터 오른쪽 방향으로 `1`부터 차례대로 값을 채운다.

각 행을 모두 채우면 다음 행으로 이동하며, 완성된 배열을 출력한다.

## 입력

배열의 크기를 나타내는 정수 `n`이 입력된다.

* `1 ≤ n ≤ 100`

## 출력

`1`부터 `n × n`까지의 정수를 `n × n` 형태로 출력한다.

각 숫자는 공백으로 구분하고, 한 행의 출력이 끝나면 줄을 바꾼다.

## 풀이 아이디어

1. 값을 저장할 2차원 배열과 배열의 크기 `n`을 선언한다.
2. 배열에 저장할 값을 `1`로 초기화한다.
3. 이중 반복문을 사용해 배열을 행 순서대로 순회한다.
4. 현재 위치에 값을 저장한 후 값을 `1`씩 증가시킨다.
5. 배열을 다시 순회하며 각 행의 값을 출력한다.

## 핵심 코드

```cpp
int value = 1;

for (int i = 0; i < n; i++)
{
  for (int j = 0; j < n; j++)
  {
    array[i][j] = value;
    value++;
  }
}

for (int i = 0; i < n; i++)
{
  for (int j = 0; j < n; j++)
  {
    cout << array[i][j] << " ";
  }
  cout << "\n";
}
```
