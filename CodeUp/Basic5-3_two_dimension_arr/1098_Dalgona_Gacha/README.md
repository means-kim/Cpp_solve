# 설탕과자 뽑기

* 문제 번호: 1098
* 출처: CodeUp
* 난이도: 기초
* 사용 언어: C++
* 문제 링크: https://codeup.kr/problem.php?id=1098

## 문제 요약

격자판의 크기와 여러 개의 막대 정보가 주어질 때, 각 막대를 지정된 위치와 방향에 맞게 배치한 후 최종 격자판의 상태를 출력하는 문제입니다.

막대가 놓인 위치는 `1`, 놓이지 않은 위치는 `0`으로 표시합니다.

## 입력

첫 번째 줄에 격자판의 세로 크기 `h`와 가로 크기 `w`가 주어집니다.

두 번째 줄에 배치할 막대의 개수 `n`이 주어집니다.

이후 `n`개의 줄에 각 막대의 정보가 다음 순서로 주어집니다.

* `l`: 막대의 길이
* `d`: 막대의 방향

  * `0`: 가로
  * `1`: 세로
* `x`, `y`: 막대를 놓기 시작할 좌표

## 출력

모든 막대를 배치한 후 격자판의 상태를 출력합니다.

막대가 놓인 위치는 `1`, 놓이지 않은 위치는 `0`으로 출력하며, 각 숫자는 공백으로 구분합니다.

## 풀이 아이디어

1. 최대 크기에 맞춰 2차원 배열을 `0`으로 초기화합니다.
2. 막대의 길이, 방향, 시작 좌표를 입력받습니다.
3. 방향이 `0`이면 열의 위치를 증가시키며 가로로 막대를 배치합니다.
4. 방향이 `1`이면 행의 위치를 증가시키며 세로로 막대를 배치합니다.
5. 모든 막대를 배치한 후 주어진 격자판의 크기만큼 배열을 출력합니다.

## 핵심 코드
