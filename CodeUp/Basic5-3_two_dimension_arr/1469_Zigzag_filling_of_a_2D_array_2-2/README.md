# 2차원 배열 역방향 지그재그 채우기 2-2

* 문제 번호: 1469
* 출처: CodeUp
* 난이도: 기초
* 사용 언어: C++
* 문제 링크: https://codeup.kr/problem.php?id=1469

## 문제 요약

정수 `n`을 입력받아 `n × n` 크기의 2차원 배열에 1부터 차례대로 값을 저장합니다.

첫 번째 행은 오른쪽에서 왼쪽으로 값을 저장하고, 다음 행은 왼쪽에서 오른쪽으로 저장하는 과정을 반복하여 지그재그 형태의 배열을 만듭니다.

## 입력

배열의 크기를 나타내는 정수 `n`이 입력됩니다.

## 출력

1부터 `n × n`까지의 값이 역방향 지그재그 형태로 저장된 2차원 배열을 출력합니다.

## 풀이 아이디어

행 번호가 짝수인지 홀수인지에 따라 열을 순회하는 방향을 다르게 설정합니다.

1. 배열에 저장할 값인 `value`를 1로 초기화합니다.
2. 짝수 번째 행은 오른쪽에서 왼쪽으로 순회하며 값을 저장합니다.
3. 홀수 번째 행은 왼쪽에서 오른쪽으로 순회하며 값을 저장합니다.
4. 완성된 배열을 행과 열 순서대로 출력합니다.

## 핵심 코드

```cpp
int value = 1;

for (int i = 0; i < n; i++)
{
  // 짝수 번째 행은 오른쪽에서 왼쪽으로 저장
  if (i % 2 == 0)
  {
    for (int j = n - 1; j >= 0; j--)
    {
      array[i][j] = value;
      value++;
    }
  }
  // 홀수 번째 행은 왼쪽에서 오른쪽으로 저장
  else
  {
    for (int j = 0; j < n; j++)
    {
      array[i][j] = value;
      value++;
    }
  }
}
```
