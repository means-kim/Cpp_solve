# [기초-배열연습] 2차원 배열 순서대로 채우기 1-6

* 문제 번호: 1465
* 출처: CodeUp
* 난이도: 기초
* 사용 언어: C++
* 문제 링크: https://codeup.kr/problem.php?id=1465

## 문제 요약

두 정수 `n`, `m`을 입력받아 `n × m` 크기의 2차원 배열을 만든다.

배열의 마지막 행부터 첫 번째 행까지 순회하며, 각 행의 왼쪽에서 오른쪽 방향으로 `1`부터 차례대로 값을 저장한다.

## 입력

배열의 행과 열의 크기를 나타내는 정수 `n`, `m`이 입력된다.

* `1 ≤ n, m ≤ 100`

## 출력

`1`부터 `n × m`까지의 정수가 아래쪽 행부터 순서대로 저장된 `n × m` 배열을 출력한다.

각 숫자는 공백으로 구분하고, 한 행의 출력이 끝나면 줄을 바꾼다.

## 풀이 아이디어

1. 값을 저장할 2차원 배열과 배열의 크기 `n`, `m`을 선언한다.
2. 배열에 저장할 값을 `1`로 초기화한다.
3. 바깥쪽 반복문은 마지막 행인 `n - 1`부터 첫 번째 행인 `0`까지 감소시키며 순회한다.
4. 안쪽 반복문은 각 행의 첫 번째 열부터 마지막 열까지 순회한다.
5. 현재 위치에 값을 저장한 후 값을 `1`씩 증가시킨다.
6. 완성된 배열을 첫 번째 행부터 순서대로 출력한다.

## 핵심 코드

```cpp
int value = 1;

for (int i = n - 1; i >= 0; i--)
{
  for (int j = 0; j < m; j++)
  {
    array[i][j] = value;
    value++;
  }
}

for (int i = 0; i < n; i++)
{
  for (int j = 0; j < m; j++)
  {
    cout << array[i][j] << " ";
  }
  cout << "\n";
}
```
