# 성실한 개미

* 문제 번호: 1099
* 출처: CodeUp
* 난이도: 기초 종합
* 사용 언어: C++
* 문제 링크: https://codeup.kr/problem.php?id=1099

## 문제 요약

10×10 크기의 미로에서 개미가 `(2, 2)` 위치부터 이동합니다.

개미는 현재 위치에서 오른쪽으로 이동할 수 있으면 오른쪽으로 이동하고, 오른쪽이 막혀 있으면 아래쪽으로 이동합니다.

이동한 위치는 `9`로 표시하며, 먹이인 `2`를 만나거나 더 이상 이동할 수 없으면 이동을 종료합니다.

## 입력

10×10 크기의 미로 정보가 입력됩니다.

* `0`: 이동할 수 있는 길
* `1`: 이동할 수 없는 벽
* `2`: 먹이가 있는 위치

## 출력

개미가 이동한 경로를 `9`로 표시한 최종 미로를 출력합니다.

## 풀이 아이디어

1. 10×10 크기의 미로 정보를 2차원 배열에 저장합니다.
2. 개미의 시작 위치를 `(2, 2)`로 설정합니다.
3. 현재 위치를 `9`로 표시합니다.
4. 현재 위치가 먹이인 `2`라면 이동을 종료합니다.
5. 오른쪽 칸이 `0` 또는 `2`라면 오른쪽으로 이동합니다.
6. 오른쪽으로 이동할 수 없다면 아래쪽 칸을 확인하고 이동합니다.
7. 오른쪽과 아래쪽 모두 이동할 수 없다면 반복을 종료합니다.
8. 개미의 이동 경로가 표시된 미로를 출력합니다.

## 핵심 코드

```cpp
int x = 2;
int y = 2;

while (true)
{
  // 현재 위치가 먹이라면 표시 후 종료
  if (maze[x][y] == 2)
  {
    maze[x][y] = 9;
    break;
  }

  // 현재 이동 경로 표시
  maze[x][y] = 9;

  // 오른쪽으로 이동
  if (maze[x][y + 1] == 0 || maze[x][y + 1] == 2)
  {
    y++;
  }
  // 오른쪽이 막혀 있으면 아래쪽으로 이동
  else if (maze[x + 1][y] == 0 || maze[x + 1][y] == 2)
  {
    x++;
  }
  // 더 이상 이동할 수 없는 경우
  else
  {
    break;
  }
}
```
